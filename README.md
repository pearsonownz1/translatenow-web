# TranslateNow

Certified translations for the filing.

## How to run

npm install
npm run dev
npm run build
npm start

Dev server uses port 3001.

## Paths

- Start an order: /order
- Request a quote: /quote
- Find an order: /find-order

Client-side demo. No auth. No database. No document storage.
USCIS and IRCC do not approve vendors.
